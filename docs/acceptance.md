# Acceptance evidence

Result of every success criterion (AAP 0.12.1), every constraint check (AAP 0.12.2) and every item
that still needs input from outside the run (AAP 0.12.3), each with the date, the commit and the mode
it was recorded in. A row is updated after the run it names: `Result`, `Date` and `Commit` are
overwritten with what that run produced. No row reads `pass` without a measurement or a test run
behind it, and a row still to be run reads `pending`.

The two blocks at the end are machine-written: end-to-end results by `pnpm test:e2e`, line counts by
`pnpm loc --write`. Run the command that owns a block and it replaces everything between that block's
markers, leaving every other line byte-identical; nothing inside a marker block is hand-edited. Status
words are `pass`, `fail`, `pending` and `blocked`, and a `blocked` or `pending` cell carries the
sentence it was recorded with.

| Mode                  | What it is                                                                                                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Stripe `mock`         | `stripe-mock` v0.206.0 behind the stateful test proxy, needing no credential; the posture `pnpm test` takes by default. Its payment results are mock evidence only (AAP 0.11.2).     |
| Stripe `test`         | The operator's test-mode secret and publishable keys, with the webhook signing secret supplied by `stripe-cli`; the posture `pnpm test:stripe` takes, and `pnpm test:e2e` with them. |
| Telephony `simulator` | The scripted telephony simulator under `apps/api/test/support/voice-simulator/` answers; no real call is placed.                                                                     |
| Telephony `staging`   | One real call per task kind to an operator-owned allowlisted number (AAP 0.12.3).                                                                                                    |
| `n/a`                 | A measurement that touches neither Stripe nor telephony.                                                                                                                             |

Commands: `pnpm test` runs the unit, integration and system suites; `pnpm test:stripe` reruns the
integration project with `STRIPE_MODE=test`; `pnpm test:e2e` starts the stack and drives the Playwright
and Maestro suites; `pnpm perf` runs the k6 load test at 50 rps; `pnpm loc` counts the delivered code.
Measurements: `pnpm --filter @tablemate/api bench:verify` for server verification,
`maestro test apps/mobile/e2e/maestro/zk-bench.yaml` for device proving, and
`pnpm --filter @tablemate/workers eval:menus` for menu accuracy.
